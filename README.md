# The Daily Adin

A modern, fast and SEO-friendly news portal for publishing articles, categories, multimedia, and real-time content. 

Built with **Next.js 15**, **TailwindCSS 3**

---

## 🛠 Development Pre-requisites
| Requirement       | Recommended                                    |
| ----------------- | ---------------------------------------------- |
| Node.js           | v20.x or later                                 |
| Yarn              | v1.x or later                                  |
| RAM               | 2GB+ (development) / 4GB+ (production)         |
| Storage           | 1GB+ free disk space                           |
| Browser           | Modern browser (Chrome, Firefox, Safari, Edge) |


---

## 📦 Installation and run

```bash
# SSH 
git clone git@gitlab.com:shahali007/daily-adin-web-app.git

# or HTTPS
git clone https://gitlab.com/shahali007/daily-adin-web-app.git


# Switch to project directory
cd daily-adin-web-app

# create .env 
# and add the information in environment file
NODE_ENV=development
BASE_URL=
NEXTAUTH_SECRET=
WEB_APP_BASE_URL=

# Install dependencies
yarn install

# Run the project
yarn dev
```
